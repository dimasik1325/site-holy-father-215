## ⚡ Особенности сайта

- **100% автономный единый файл (`index.html`):** Все стили, адаптивная верстка, SVG-иконки, интерактивные скрипты, встроенный QR-код и звуковые эффекты упакованы в один файл без зависимостей.
- **Плашка и раздел «Аукцион каждый день»:** Выделенный интерактивный баннер и категории лотов (Колесо игр, Хардкорные челленджи, Заказ музыки).
- **Блок Доната с QR-кодом:** Встроенный QR-код с неоновой рамкой, анимацией лазерного сканирования, кнопками быстрых сумм и копированием ссылки в буфер обмена.
- **Интерактивный плеер:** Симуляция чата зрителей, счетчик онлайна, звуковые эффекты Web Audio API.
- **Таймер расписания:** Точный обратный отсчет до 20:00 по московскому времени и подсветка текущего дня.
- **Интерактивное голосование Telegram:** Виджет опроса зрителей прямо на сайте.

## 🚀 Как включить сайт на GitHub Pages

1. Откройте вкладку **Settings** в репозитории: [Настройки Pages](https://github.com/dimasik1325/site-holy-father-215/settings/pages).
2. В блоке **Build and deployment** выберите **Source:** `Deploy from a branch`.
3. Укажите ветку **`main`** и каталог **`/ (root)`**, затем нажмите **Save**.
4. Сайт будет доступен по ссылке: **https://dimasik1325.github.io/site-holy-father-215/**
