- **Смешанный игровой дизайн (CS2 + Minecraft + Twitch):**
  - Тактический HUD в стиле CS2 (оранжевый неон, тактические бейджи, прицелы, стальной металл)
  - Атмосфера Minecraft (кубические элементы, полоса опыта XP 215 уровня, алмазный и изумрудный неон)
  - Фирменный фиолетовый стиль Twitch с живым индикатором стрима
- **Интерактивный плеер с переключением режимов:**
  - `🎯 CS2` / `⛏️ Minecraft` / `🔨 Аук & Чат` с динамической сменой интерфейса и сообщений зрителей
- **100% видимый блок QR-кода доната:**
  - Исправлены проблемы с переполнением: QR-код расположен по центру в стильном кейсе со сканирующим лучом
  - Строка ссылки защищена от вылетания за границы экрана, кнопка «Скопировать» всегда полностью видна
- **Плашка ежедневного аукциона:**

## 🚀 Как включить сайт на GitHub Pages

1. Откройте [Настройки Pages](https://github.com/dimasik1325/site-holy-father-215/settings/pages).
2. В **Build and deployment** выберите **Source:** `Deploy from a branch`.
3. Укажите ветку **`main`** и папку **`/ (root)`**, нажмите **Save**.
4. Сайт будет открываться по адресу: **https://dimasik1325.github.io/site-holy-father-215/**
