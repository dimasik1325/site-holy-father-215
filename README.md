# HOLY_FATHER_215 — Официальный лендинг Twitch-канала

Одностраничный сайт-лендинг для стримера **holy_father_215**.

- **Twitch канал:** [twitch.tv/holy_father_215](https://www.twitch.tv/holy_father_215)
- **Telegram канал:** [t.me/holyfather215](https://t.me/holyfather215)
- **Расписание:** Стримы 6 дней в неделю в 20:00 по МСК (воскресенье — по голосованию в Telegram)

---

## 🚀 Особенности реализации

- **Полностью в одном автономном файле:** `index.html` содержит в себе всю структуру, вшитые SVG-иконки, CSS-стили, интерактивный плеер, расписание, интерактивное голосование и Web Audio звуковые эффекты без необходимости внешних сборок или node_modules.
- **Готов к GitHub Pages:** Файл `index.html` находится в корне репозитория и может быть мгновенно включен на GitHub Pages.
- **Адаптивный дизайн:** Корректное отображение на смартфонах, планшетах и мониторах любого разрешения.
- **Интерактивные элементы:**
  - Таймер обратного отсчёта до следующего стрима (20:00 МСК)
  - Симуляция стрима со звуками клика/переключения
  - Живой счетчик зрителей с анимацией
  - Виджет интерактивного голосования для воскресного стрима
  - Модальное окно «Поделиться» и копирование ссылки на канал в буфер обмена
