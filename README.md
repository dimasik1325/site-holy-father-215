## 🎨 Особенности сайта

- **Кинематографичные обои (Minecraft × CS2 × Twitch):**
  - Эксклюзивный фоновый арт, объединяющий кубические алмазные блоки Minecraft, неоновый символ Twitch и тактический огонь с искрами CS2.
  - Мягкое затемнение и стеклянный эффект карточек, благодаря чему текст читается легко и контрастно.
- **Единый автономный HTML-файл (`index.html`):**
  - Все обои, QR-код, SVG-иконки, CSS-стили и JavaScript упакованы в один файл.
- **Плашка ежедневного аукциона:**
  - Яркий золотой баннер: аукцион проводится каждый день в 20:00 МСК на каждом стриме!
- **Отдельный блок Доната с QR-кодом:**
  - 100% видимый QR-код по центру с неоновой подсветкой и сканирующим лазером.
  - Кнопка «Скопировать ссылку» и кнопка прямого перехода на DonationAlerts (защищены от вылетания за границы экрана).
- **Интерактивный стрим-плеер:**
  - Симуляция стрима Holy_Father_215, чат зрителей, звуки реакций (Web Audio API).
- **Расписание и таймер:**
  - Точный таймер обратного отсчета до 20:00 МСК и опрос в Telegram.

## 🚀 Как включить сайт на GitHub Pages

1. Откройте [Настройки Pages](https://github.com/dimasik1325/site-holy-father-215/settings/pages).
2. В **Build and deployment** выберите **Source:** `Deploy from a branch`.
3. Укажите ветку **`main`** и папку **`/ (root)`**, нажмите **Save**.
4. Сайт будет открываться по адресу: **https://dimasik1325.github.io/site-holy-father-215/**
